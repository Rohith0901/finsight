# Tech-debt register

Known shortcuts, gaps and risks, ranked so the team works on what matters
first. Review it at each phase boundary; add an item whenever a PR takes a
shortcut.

**Scoring.** Impact (1-5, how much it hurts users or the review), Risk (1-5,
how likely and how bad if ignored), Effort (1-5, 1 = an afternoon).
**Priority = (Impact + Risk) × (6 − Effort).** Higher first.

## Resolved

| Item | How |
| --- | --- |
| Shared in-memory database made app tests depend on each other | `singleInstance: false` in `test/support.dart` |
| UPI handles with digits (`rahul.sharma99@…`) sent real names to the server | Digits removed before the person check, in both twins, with fixtures |
| Paying one friend and being repaid by another was marked a self transfer | Both sides must name the same person (or no one); test added |
| Classifier evaluated on rows the phone resolves itself (known brands, hinted salary) | Evaluation and training use only rows the model sees |
| Recurring false positives from 2-payment coincidences | Minimum 3 payments, ±5% amounts within busy merchants |
