# FinSight evaluation report

Dataset synth-2026.09, 60 synthetic users, model v1. Generated by `python -m finsight_ml.evaluate`.

> **Synthetic data.** The generator and the parser were written by the same team, so these numbers are optimistic. They show the pipeline works and catch regressions. Present only the real-data section as findings.
